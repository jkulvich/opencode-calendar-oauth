# OpenCode Calendar

Страница проекта и политика конфиденциальности для личной интеграции

opencode с доступом к Google Calendar. Используется как `homepage URL` и
`privacy policy URL` в экране согласия Google OAuth.

- `index.html` — что делает интеграция и какие разрешения запрашивает
- `privacy.html` — где хранятся данные и как отозвать доступ
